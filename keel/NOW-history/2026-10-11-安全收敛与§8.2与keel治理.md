  + common-string 再导出 ⇒ 收敛为 **common-security 单一真相源**（dom-runtime 改再导出）。

  单一真相源，未新造实现。

## 2026-10-11 · §8.2 第三/四步

- **事件×2 收敛**：核实 `@lytjs/shared-types` 全局仅被 `import type` 消费 ⇒ 其
  `EventEmitter`/`createEventEmitter` 是死导出，删除 ⇒ `common-events` 成唯一真相源。
- **真 AOT MVP**：仓内原本**无**真 AOT（旧 `precompileTemplate` 只返回 `compiled.code`、丢了
  import 前缀）。改为构建期产出**可直接 `import()` 的 ESM 模块源**（helper import + `export { render }`，
  **无 `new Function`**）；3 用例 + 缺陷注入（丢弃前缀 ⇒ `ReferenceError` ⇒ 3 条变红）。
- **benchmark 实测**：修好坏掉的脚手架（`bench()` 不执行 `beforeEach` ⇒ container 恒 undefined；
  `render.bench.ts` 从 `@lytjs/vdom` 导入不存在的 `h`）⇒ 落地 6 套件 / 59 项真实数字，
  替换 README 自承不可信的历史口径。

## 症状

公开选项被声明、被文档化、被测试"覆盖"，却**从不影响产物**：翻转开关，产物逐字节相同
（或只多打一次告警）。使用方按文档接入后**什么都不会发生，也不报错**。

## 根因

开关只被**声明**、未被**消费**，四种形态：① 从未读取（`@lytjs/ssg` 早声明 `@lytjs/ssr`
依赖却零引用）；② 被同义子开关覆盖（`compile()` 只认 `ssrMode`，调用方传的 `ssr` 被内部
`ssr: ssrMode ?? false` 抹成 `false`）；③ 落在空 if 块；④ 只做半件事（不渲染不写盘却报 success）。

## 正解

- 每个公开开关必须有**产物级**断言：翻转开关 ⇒ 断言必须变红（不是断言"函数被调用过"）；
- `if (x) { }` 空块 = 红线：要么删分支，要么删字段，不留"预留"；
- 同义双名开关（`ssr` / `ssrMode`）必须合并或显式互斥；
- 排查顺序：先跑探针**逐字节对比两态产物**，再谈实现。

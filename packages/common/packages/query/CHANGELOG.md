# @lytjs/common-query 更新日志

## [未发布] - 2026-11-03

### 🐞 修复

- **`+` 未按 form 编码解码为空格**：`decodeURIComponent('a+b')` 仍是 `"a+b"`，而浏览器把
  搜索框里的 `a b` 编码成 `?q=a+b` ⇒ 搜索「a b」永远搜不到。现在键与值都先做 `+ → 空格`
  再解码；真正的加号由发送方编码为 `%2B`，不受影响。
- 畸形转义（`%zz`）保留原串而不抛错（此前 `try/catch` 已覆盖，补充回归用例）。

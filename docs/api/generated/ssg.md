# @lytjs/ssg

静态站点生成（SSG）支持

## 目录

- [SSGConfig](#ssgconfig)
- [SSGResult](#ssgresult)
- [SSGGenerator](#ssggenerator)

## SSGConfig

**Interface**

### 成员

| 名称    | 类型         | 描述                                            | 可选 |
| ------- | ------------ | ----------------------------------------------- | ---- |
| pages   | `SSGPage[]`  | 待生成的页面（每页含已构建好的 VNode 组件）     | 否   |
| options | `SSGOptions` | 生成选项：输出目录 / baseUrl / sitemap / ISR 等 | 是   |

## SSGResult

**Interface**

### 成员

| 名称     | 类型     | 描述                                          | 可选 |
| -------- | -------- | --------------------------------------------- | ---- |
| filePath | `string` | 相对输出目录的文件路径，如 `about/index.html` | 否   |
| html     | `string` | 页面完整 HTML                                 | 否   |

## SSGGenerator

**Class**

SSG 生成器（对 `@lytjs/ssr` 真实实现的薄封装）。

### 成员

| 名称     | 类型 | 描述                                                                                                                             | 可选 |
| -------- | ---- | -------------------------------------------------------------------------------------------------------------------------------- | ---- |
| generate | -    | 生成静态页面 HTML（**真正渲染**）。 只计算、不写盘 —— 便于测试，或由调用方自行决定落盘策略（如上传到 CDN）。 需要直接写盘请用 。 | 否   |
| write    | -    | 生成并**写盘**（含 sitemap，若选项开启）。                                                                                       | 否   |
